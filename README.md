# תרגול אק״ג — הכנה לסבבים קליניים

אתר לימוד ותרגול אינטראקטיבי בעברית (RTL) לסטודנט רפואה שנה 4, מבוסס מצגת תרגול אק״ג (קצב ומקצב + מוניטור).

## Live
https://nadavmruskin-boop.github.io/ecg-practice/

## תוכן
- מודול תיאוריה (bottom line → מנגנון → דוגמה → memory hook → ביקורת עצמית)
- תרגול עם סטריפים אמיתיים מהמצגת + שאלות עיוניות
- ניקוד ומעקב טעויות (localStorage)

## הרצה מקומית
פתחו את `index.html` בדפדפן, או:
```bash
python3 -m http.server 8080
```
